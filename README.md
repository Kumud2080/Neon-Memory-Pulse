# Neon Memory Pulse

A fast-paced Simon-style memory game built with HTML, CSS, 
JavaScript, and jQuery. Follow the glowing color sequence 
and repeat it accurately as patterns grow longer.

## Features
- Progressive difficulty — sequences grow with each level
- Sound feedback for every input
- Smooth neon animations on a dark UI
- Detects wrong input and resets with feedback

## Tech Stack
HTML · CSS · JavaScript · jQuery
